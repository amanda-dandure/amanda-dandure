## Featured Projects

### [jobboard-api](https://github.com/amanda-dandure/jobboard-api)
RESTful job board API with role-based auth (employers and job seekers), full-text search, cursor pagination, async email notifications via Celery, and auto-generated OpenAPI docs.  
`Django 5` `DRF` `PostgreSQL` `Celery` `Redis` `Docker` `pytest`

### [jobflow-ai](https://github.com/amanda-dandure/jobflow-ai)
AI-powered job application tracker. Kanban board with one-click status updates (HTMX), Claude-generated cover letters tailored to each role, and interview prep question generation.  
`Django` `Claude API` `HTMX` `Tailwind CSS` `Alpine.js`
